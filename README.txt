# NahstyDev Auto File Organizer

A simple desktop app that automatically organizes messy folders into clean categories.

## Features
- GUI interface (no coding needed)
- Preview before organizing
- Supports images, videos, documents, and more

## Demo
https://youtu.be/r-tVDkjT5kI

## Use Case
Perfect for cleaning up Downloads folders or automating file management.

## Built With
Python (Tkinter)

## 🚀 Quick Start (No Coding Needed)

1. Make sure Python is installed
2. Double-click `run.bat`
3. Use the app

## Alternative Run Method

Run this in terminal:
python gui_organizer.py
